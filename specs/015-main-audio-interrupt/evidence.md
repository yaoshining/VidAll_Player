## 模拟器

使用带声 AAC 样片和申请独立音频焦点的静音闹铃。每阶段测量八次扬声器峰值，并记录消费端实际播放状态和进度。两台模拟器在打断和解除两个阶段均显示暂停，十六次采样全零；解除后只调用一次播放。

| 设备 | 打断及解除后的进度（秒） | 手动恢复后（秒） | 恢复峰值 |
| --- | --- | --- | --- |
| API 19 TV | 3.500 | 4.417 → 5.750 | 0.0101 |
| API 20 平板 | 3.250 | 3.917 → 5.333 | 0.0034 |

验收范围为系统实际送达的音频打断。未在实体 TV 或 API 15–18 上复测；未改动 VidAll_TV 正式依赖。

API 19 换集与退出使用相同主包和 CI 核心，独立测试模块额外控制闹铃生命周期（SHA-256 `5806cddf7694b8f7b06c1c76a2748b8636c01a9434f64c9ac0cb6ea84ad2111a`）。第一集被打断停在 3.500 秒，闹铃解除后用播放器的“下一集”打开第二集，进度由 0.083 走到 1.500 秒且有声。第二集另一次被打断停在 3.417 秒，在闹铃仍活动时退出，然后解除并打开第一集，进度由 0 走到 1.083 秒且有声。
