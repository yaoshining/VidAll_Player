# 008：DevEco26 私有归档的本地资产准备

本阶段只准备将来可能上传私有 Release 的两片原始 ZIP 和清单。用户已批准本地实施，未批准创建仓库、Release、上传、push、Secret、环境、变量或 ruleset。私有仓库名称、许可范围、身份权限均以独立精确预览待批。

## 验收

- A1 只读旧 archive-lock，原包大小/完整 SHA 一致；固定 chunk=2,097,152,000 字节，每片严格小于 2 GiB。原包两片为 2,097,152,000 和 1,981,328,294 字节。
- A2 新输出目录独占创建；拒绝既有目录、符号链接、路径逃逸及非普通输入。失败清理自己创建的部分产物，禁止覆盖或删除既有内容。
- A3 manifest 确定性记录原官方来源历史、固定序号/offset/bytes/片 SHA、完整 ZIP SHA；无私密路径、签名 query 或凭据。来源仍是原官方 HTTPS 包计算值，不冒称独立厂商摘要。
- A4 独立 verify 按可信旧锁与固定布局核 manifest，流式读片复算完整拼接 SHA；缺片、额外片、错序、重复、篡改、摘要/尺寸或路径不符均失败。不信任 manifest 自报整体身份。
- A5 生成真实两片后验证原包前后身份、全部资产精确 bytes/SHA，整理私有仓库/Release/资产/权限预览；远端操作继续待批。

不实现云端下载器、不改 #82 workflow、产品 API、八库、旧锁、006/007 封存、TV/候选。不运行构建/HAR/设备/长播。应用与平台验收仍待验收。
