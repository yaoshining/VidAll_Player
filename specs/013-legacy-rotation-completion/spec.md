# #84 兼容播放器旋转与正常播完

第一版于 2026-11-08 通过 R1–R5 验收；第二版已交付 VidAll_TV，等待同包设备复验。[设备回执与覆盖范围](tasks.md#2026-11-08-消费端验收)

前置依据为 #83 的消费端验收回执。以兼容分支 32bb822 为交付基线。

- R1　GL/SW 在暂停、连续旋转及缩窗时成对读取宽高，即使没有新解码帧也重绘。GL 根据实际 EGL 表面尺寸绘制。窗口配置失败须停止使用失败的渲染器，可通过重新绑定恢复。
- R2　Vulkan 重新绑定时提交新窗口的尺寸，分离时释放桥持有的窗口。保留 #83 已通过的尺寸通知、失败回滚与代际检查。
- R3　一次加载对应一个 mpv 命令身份及一个播放列表条目。匹配的正常 EOF 最多产生一次公开 completed 状态。停止、错误、返回、切源及身份不明的迟到消息均不得触发下一集。
- R4　保持旧初始化、公开接口、核心及 C++ 运行库。由普通分支 iMac GitHub Actions 完整构建、审计和交付独立 HAR。
- R5　用同一候选包依次验证模拟器、云平板和 TV 的播放、暂停旋转、恢复、拖动、返回重开、续播、自动下一集、取消倒计时及焦点。

## 审查后的第二版候选

当前媒体的 EOF 和错误都须与已提交的 loadfile 条目匹配。命令回复晚到时只追认匹配条目的首个结束原因。窗口分离期间的正常 EOF 延至重新绑定后交付，停止、切源或释放均撤销待发事件。GL 更换窗口时维持可安全释放 renderer 的当前上下文。SW 暂停重绘遇到暂时无法取得的缓冲时须重试。代理媒体播完后调用 stop 须请求归还租约。
