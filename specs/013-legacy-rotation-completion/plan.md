# 实施与宪章检查

先以平台替身执行兼容分支的生产渲染循环和事件分发，记录失败，再逐项接入旧草案中能通过验证的部分。保留既有 Vulkan Resize 回滚。渲染线程在同一锁下取得一组宽高；加载命令与 END_FILE 按条目身份关联，ArkTS 复核媒体上下文后使用现有状态事件。

宪章检查：使用旧 SDK 已提供的 NativeWindow、EGL、mpv 接口；其中 eglQuerySurface 属于 EGL 1.0，动态依赖仍为原有 libEGL。保持 API 15 安装下限、API 22 目标，无新权限或 FFmpeg 构建。原生窗口与回调分别按现有生命周期释放。自动连播、倒计时、焦点由消费端负责。主机测试、iMac CI 实物及设备回执分开记录。

一致性检查：R1/R2 对应渲染循环和 Vulkan 的主机测试，R3 对应原生事件及 ArkTS 会话测试，R4 对应构建、固定库和 ELF 审计，R5 只由本轮设备回执确认。
