# No-Go 验证用例

| 编号 | 检查 | 预期结果 |
| --- | --- | --- |
| NG-001 | G1、G2、G3 的负责人确认存在性 | 任一缺失时候选保持 `blocked`。 |
| NG-002 | 文档是否出现已支持、可播放或真实首帧通过的无证据声明 | 不得出现；否则验证失败。 |
| NG-003 | 方案是否包含 AVPlayer 或回退 | 不得出现；否则立即失败。 |
| NG-004 | 是否生成 HAR、原生产物、NAPI bridge、播放器或 fixture 实现 | 不得生成；否则超出当前范围。 |
| NG-005 | 是否修改、构建、提交或依赖 VidAll_TV | 不得发生；否则立即失败。 |
| NG-006 | G2 材料是否能证明同一候选的来源、许可证、加载和 ABI/ELF | 缺失任何项时不得准入。 |
| NG-007 | G3 是否有指定真机的 NativeWindow/EGL/GLES 真路径记录 | 缺失时不得声明画面或首帧能力。 |
| NG-008 | 能力三态是否正确 | `已构建待验证` 不得作为支持表述。 |
