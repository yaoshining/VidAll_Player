# API 19 TV 音频中断（#89）

消费端使用 #84 的兼容 HAR，基线为 `3970814`。本次交付沿用其库布局和宿主 FFmpeg 六库。

- R1　API 15–19 的 OHAudio 渲染器收到 PAUSE 或 STOP 时，当前媒体进入 mpv 的用户暂停状态，声音归零、时间停止、界面显示暂停。RESUME 不自动恢复；用户一次播放即可恢复同一媒体。音量提示不应触发暂停。
- R2　退出、快速切源或自然换集后，旧渲染器的通知和旧文件的中断暂停均不能改变新媒体。
- R3　API 20 及以上保留已有写入回调和消费端会话策略。所有版本均须保留数据输出、软解和既有 OHCodec 互操作。
- R4　交付同仓 iMac 自托管 GitHub Actions 完整构建的兼容 HAR，记录提交、运行、哈希和消费端复验。验收样片为带非零输出的 AAC，闹铃自身输出全零。
