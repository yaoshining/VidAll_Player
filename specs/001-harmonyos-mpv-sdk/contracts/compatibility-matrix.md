# IJK 兼容矩阵与渐进迁移契约

矩阵只定义 VidAll_Player 兼容目标和独立验证；不得读取、修改、构建、提交或发布 VidAll_TV。

| IJK 基线 | SDK 契约 | 独立验证 | 开关/回退 | 证据 |
|---|---|---|---|---|
| 媒体浏览输入 | `MediaSource` 校验 | consumer-smoke 本地/网络样本 | `playerEngine=ijk|vidall`；输入错误回退 `ijk` | 三态、匿名样本、错误码 |
| WebDAV | 受控 Basic/TLS/重定向/Range | 受控测试服务，覆盖同信任范围携带认证、跨范围剥离认证、Range、超时和断网 | 认证、证书或重定向策略失败回退 `ijk` | 三态、脱敏网络摘要、重定向决策、Range/恢复结果 |
| SMB localhost HTTP | `localhostProxy`/lease | loopback HTTP 的 Range、跳转、`acquired`/续期/释放请求/确认、失效和异常清理 | 代理失效、未确认释放或清理失败回退 `ijk` | 三态、匿名 lease 状态序列、释放确认或失败原因 |
| 音轨/字幕 | `PlayerTrack`、外挂字幕、延迟 | 多轨、SRT、ASS、网络字幕样本 | 渲染降级/不支持回退 `ijk` | 三态、语言/渲染结论 |
| 音频路由 | 音量、静音、音频参数/错误 | ARM64 TV 音频设备样本 | 路由失败回退 `ijk` | 三态、音频参数和限制 |
| 硬解回退 | 硬解状态、选定解码器、软解回退原因 | ARM64 TV 编解码样本 | 硬解失败时软件解码；性能不达标回退 `ijk` | 三态、指标、回退原因 |
| 跳转/播放控制 | play/pause/seek/speed/volume | 连续控制压力样本 | 状态不一致回退 `ijk` | 三态、事件序列 |
| 生命周期 | surface 重建、后台、切源、stop/release | 独立示例 100 次核心冒烟 | 泄漏、死锁或旧回调回退 `ijk` | 三态、状态序列、释放记录 |

## 行字段与迁移规则

每行必须记录：组件版本、来源提交、锁定摘要、目标 ABI、API 15/19/22 记录、设备类别（ARM64 真机或仅兼容辅助的模拟器）、匿名设备、匿名样本、执行时间、预期 IJK 行为、实际 SDK 结果、`eventEpoch`/序号/Surface generation 观察结果、三态、指标、已知限制、证据文件和回退决定。HTTP/WebDAV 行还必须记录认证是否被转发/剥离及重定向信任判定；SMB proxy 行还必须记录匿名 lease 状态序列、释放确认或异常清理结果。三态只能为“已通过真机样本”“已构建待验证”“不支持或暂缓”。

功能开关属于消费方配置；推荐顺序是先完成隔离消费者验证和 ARM64 真机门禁，再由集成方在其仓库对单一场景灰度选择 `vidall`，保留 `ijk` 默认回退，逐项扩大。遇到错误、性能不达标、泄漏、证据过期或未验证能力必须立即选择 `ijk`。本库不得读取、修改、构建、提交或发布 VidAll_TV，也不得把该矩阵当作已改造 VidAll_TV 的证明。
